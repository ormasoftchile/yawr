# Yawr runbook previsualization experiment

This non-production sandbox tests two review interactions that may be useful in
the VS Code graph: semantic step grouping and opt-in decision/exception lenses.

It uses one neutral, hand-authored graph. It does not parse a runbook, execute
Yawr, model runtime state, or provide runtime evidence.

```powershell
npm install
npm test
npm run build
npm run dev
```
