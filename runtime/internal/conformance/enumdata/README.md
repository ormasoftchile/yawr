# Enum conformance corpus

This directory contains the canonical in-repository enum corpus and the shared
vector schema used by enum and package-resolution vectors.

The executable corpus contains 72 vectors. A smaller private historical corpus
at `yawr-private@1990a6c7749dc6ee109d1e197815d6f2ed83d122` was compared by
stable ID during consolidation; differing collisions were rejected in favor
of these executable definitions. See `../CONSOLIDATION.md`.
